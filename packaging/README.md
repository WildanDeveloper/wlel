# Package-manager manifests

These files are generated by `scripts/packaging.sh` from a release's
`SHA256SUMS`, so the URLs and hashes can never disagree with the archives that
were actually published.

```sh
# after a release exists
curl -sLO https://github.com/WildanDeveloper/wlel/releases/download/v1.2.0/SHA256SUMS
./scripts/packaging.sh 1.2.0 SHA256SUMS
git add packaging && git commit -m "packaging: v1.2.0"
```

## Homebrew

`homebrew/wlel.rb` is a formula for a tap. Publish it by pushing this file to a
repository named `homebrew-<something>`:

```sh
# once
gh repo create WildanDeveloper/homebrew-wlel --public
git clone https://github.com/WildanDeveloper/homebrew-wlel /tmp/homebrew-wlel
mkdir -p /tmp/homebrew-wlel/Formula
cp packaging/homebrew/wlel.rb /tmp/homebrew-wlel/Formula/
cd /tmp/homebrew-wlel && git add . && git commit -m "wlel 1.2.0" && git push
```

Users then run:

```sh
brew install WildanDeveloper/wlel/wlel
```

The formula installs the prebuilt binary, keeps the README in `share/doc`, and
its `test do` block asserts `wlel --version`, so `brew test wlel` fails if the
archive is empty or the wrong architecture.

## Scoop

`scoop/wlel.json` is a manifest for a bucket (a repository named
`<something>-bucket` with a `bucket/` directory):

```sh
git clone https://github.com/WildanDeveloper/scoop-wlel /tmp/scoop-wlel
mkdir -p /tmp/scoop-wlel/bucket
cp packaging/scoop/wlel.json /tmp/scoop-wlel/bucket/
cd /tmp/scoop-wlel && git add . && git commit -m "wlel 1.2.0" && git push
```

Users then run:

```sh
scoop bucket add wlel https://github.com/WildanDeveloper/scoop-wlel
scoop install wlel
```

`checkver`/`autoupdate` read the GitHub releases, so `scoop update` picks up
new versions without editing the manifest.

## Why generated

Both manifests embed a SHA256 per archive. Hand-editing them is exactly the
kind of change that silently ships a wrong hash and breaks installs for
everyone on one platform, so the values come from the release's own
`SHA256SUMS` and `tests/distribution_tests.rs` checks that no placeholder
survives and that the version matches `Cargo.toml`.
